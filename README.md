# Tracker electoral

Prototipo de una página de escrutinio en vivo, por departamento.

Hoy muestra una **simulación**: los resultados son los del provisorio oficial de la elección a gobernador de Entre Ríos 2023, pero el orden y la hora en que entran las mesas están simulados.

Es un sitio estático (HTML, CSS y JavaScript, sin dependencias). Para verlo localmente:

```bash
python -m http.server 8765
```
